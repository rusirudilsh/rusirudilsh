## 🚀 About Me

I'm a Software Engineer with strong experience in designing, developing and deploying real-world business applications using modern backend, frontend, cloud and DevOps technologies.

I enjoy solving complex engineering problems, designing clean APIs, improving system reliability, maintainability, performance, security and building platforms that create measurable business value.

Currently exploring and building around:

- ⚙️ Cloud-native platforms using **Azure**, **AWS**, **Docker** and **CI/CD**
- 🧠 Scalable backend systems with **.NET**, **NestJS**, **SQL Server** and **PostgreSQL**
- 🏗️ Clean architecture, system design, event-driven workflows and API-first development
- 📊 Data processing, automation and reporting systems
